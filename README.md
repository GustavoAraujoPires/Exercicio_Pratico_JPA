# Projeto Exemplo

Este projeto é uma demonstração de como usar JPA em uma aplicação Java.

## Funcionalidades
- Persistência de dados na base de dados
- Consultas SQL através de métodos do JPA

## Requisitos
- Java 11 ou superior
- Maven 3.6.3 ou superior

## Como Executar
1. Clone o repositório
   ```bash
   git clone https://github.com/GustavoAraujoPires/Exercicio_Pratico_JPA.git
   ```
2. Navegue até o diretório do projeto
   ```bash
   cd Exercicio_Pratico_JPA
   ```
3. Compile o projeto usando Maven
   ```bash
   mvn clean install
   ```
4. Execute a aplicação
